# Conventional Commits

| Type       | Description                             | Example                                |
| ---------- | --------------------------------------- | -------------------------------------- |
| `feat`     | Add a new feature                       | `feat: add OpenRouter support`         |
| `fix`      | Fix a bug                               | `fix: fix retry handling`              |
| `docs`     | Documentation changes                   | `docs: update README`                  |
| `style`    | Formatting or style changes             | `style: format imports`                |
| `refactor` | Refactor code without changing behavior | `refactor: simplify provider handling` |
| `perf`     | Improve performance                     | `perf: optimize caching`               |
| `test`     | Add or modify tests                     | `test: add OpenRouter tests`           |
| `build`    | Build system or dependency changes      | `build: update dependencies`           |
| `ci`       | CI/CD configuration changes             | `ci: update GitHub Actions`            |
| `chore`    | Maintenance or miscellaneous changes    | `chore: remove unused code`            |
| `revert`   | Revert a previous commit                | `revert: feat: add OpenRouter support` |
