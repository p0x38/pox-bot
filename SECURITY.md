# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in pox-bot, please report it privately rather than opening a public issue.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant logs or code snippets

We will review security reports and work toward resolving confirmed vulnerabilities as soon as reasonably possible.

## Supported Versions

Security fixes are provided for the latest version of the `main` branch.
